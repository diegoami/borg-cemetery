# Balanced999 preparation: canonical evidence

**In progress:** completed source harvests for Mage, Druid, Priest and
Necromancer (111 selected starts each); the remaining five classes are running
in [Zoo43979480269](https://github.com/diegoami/borg-zoo/actions/runs/43979480269).
This is not yet a complete999-case bank or a full saved-scenario execution.
Target: equal111 for every one of nine classes, overriding caster weighting.

All325 natural deaths from these four completed harvests have their original
native packets, including unselected deaths, source/build/configuration/seed,
expected key/state/message hashes and content-derived ID sidecars. Original
packet bytes are unchanged. Private source namespaces retain their historical
aliases; aliases are path-scoped. Repeats and same-life incidents are correlated.
`retention.json` in each class records the original raw artifact ZIP's GitHub
identity/digest and each retained compact file. All attempted-life journals,
selection reasons and checkpoint inventories are retained. The original raw
ZIPs are also retained locally unchanged; Actions raw artifacts initially have
seven-day retention. No permanent remote raw-stream retention is claimed here.

`reproduction-recipes.json` indexes325 validated birth recipes. Exact applied
`borg.txt` copies are reconstructed from pinned source with its harness's
race/class/death substitutions, then checked against every original death
hash; the profile/runtime manifest are shared. Use `scripts/reproduce_native_death.py`
with a recipe, exact source checkout and original binary, or explicitly qualify
a rebuilt binary. Original cloud binary/game data are in the pinned preparation
build artifact (90-day retention); their file inventory is in
`reproduction-inputs/runtime.json`. No recorder recording is needed.

One original Druid death (seed1020002, level1) was actually reproduced locally
with the exact cloud binary: same endpoint and all three key/state/message
streams. The receipt is in `reproduction-checks/c2-r4-s1020002/`. This is a
repeat of that life, not an additional independent death. Other birth recipes
are validated inputs, not yet verified endpoint replays.

Candidate near-deaths mean observed actual HP loss to≤25% then recovery≥50%;
qualified counterfactual lethality remains unavailable. Snapshot selection and
full suite manifests will be appended after all class quotas complete.
Canonical gameplay evidence stays here; Zoo owns aggregate execution reports.
